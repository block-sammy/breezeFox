# breezeFox
🍃 BreezeFox est un kit de configuration open-source pour Firefox. Conçu pour les adeptes de la vie privée, il élimine toute la télémétrie, bloque les traceurs et désactive l'IA de Mozilla. Son fichier de configuration sur-mesure garantit un navigateur plus propre, ultra-rapide et totalement débarrassé du superflu.
